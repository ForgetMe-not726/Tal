# 审校判断标准

本文件是语言、命题、课程对齐、难度和 Cambridge 合规的单一判断来源。教材结构和检查顺序见 `references/review-list.md`。

## 1. 范围、证据与结果

目标学生为 CEFR B1、向 B2 过渡；CEFR B1 至 B2 的完整能力带均属合理材料范围，不为单题换算 Cambridge English Scale 分数。

证据冲突依次采用：用户当前要求 → 适用 Cambridge/CEFR、审校当日权威事实与严格英式英语 → 内置 review list → 正式大纲、课件和教学目标 → 被审材料 → 一般编辑知识。用户可设定范围和内部体例，但不能把已证伪、过时或违反 Cambridge 官方规则的内容判为正确。人工终审反馈可暴露漏检视角，但其中受排期、版面、成本或其他因素影响的具体改法不自动成为标准。任何低优先级证据均不能降低事实准确与时效、Cambridge 官方格式、英式英语、答案唯一性、所学所练或难度上限。

内部每个原子项只使用：

- `通过`：决定性材料齐全，全部要求满足。
- `需要修改`：存在可定位的不合规事实。
- `材料未提供无法核查`：缺答案、音视频、原文、图片、大纲或其他决定性材料。

主要维度：事实与时效、语言/Cambridge、所学所练、答案正确且唯一、难度边界、难度递进。次重点：文化与安全、图片与版式；全部原子检查映射到对应教材元素和源行。元素层面只保留一个汇总结论：已确认错误优先为`需要修改`，仅缺决定性材料为`材料未提供无法核查`，全部有证据满足才为`通过`。

缺正式大纲或对应学生用书时，不能用当前材料证明“不遗漏、不超纲”。

缺证按依赖范围登记：没有大纲不妨碍核对页面拼写，缺正式答案不妨碍独立求解但不能证明答案表一致，缺音频不能推断听力答案。一个元素内分别记录各维度，最终按错误优先汇总。无法取得外部语言证据时仅将有争议的义项/结构留为未决，不把已能判断的全部语言项目标为缺证。

## 2.1 分层门控与强制回查

审校按“资产清单 → 红线门控 → 触发式深审 → 收口回查”执行。先把页面、模块、题块和证据登记一次，再在同一清单上关闭门控；不得为每个元素反复通读全部 reference，也不得在门控未完成时因报告去重而合并元素。

| 门控 | 必须建立的证据 | 直接不通过信号 |
| --- | --- | --- |
| `G-FRAME` 框架连续性 | 页面成对表：页码、编号、标题、背景色、容器、对齐、作答格式；同一题组逐项比较跨页状态 | 同一视觉角色无依据换色、换容器、断编号、断作答区或版式改变任务含义 |
| `G-BIND` 模块身份与题块绑定 | 模块签名和双向绑定表：标题/模块号/题型 ↔ 词库、题目、图片、文本/音视频、答案；组件 ↔ 题号/页面；除非题干明确允许复用，每个 box 词和空格均须有唯一合法归属 | 词库或材料零链接、链接到另一模块、空格调用未列材料、数量不闭合、整组题与材料无关 |
| `G-OFFICIAL` 官方任务契约 | 对象、材料、动作、答案单位、题数、选项/字数、示例、评分条件、作答区；Cambridge 任务另记级别、Part、具体题型和必要时间 | 标签、Part、题型、题数、选项、字数或动作任一缺失/错配；`Exam tip` 只有空标题或泛泛级别，没有紧邻任务的具体题型与动作 |
| `G-LANGUAGE` 语言 | 全书扫描后逐元素记录英式拼写、语法、搭配、语域、标点、日期时间、引号、音标和跨媒介一致性 | 美式教材自有形式、英美混用、非标准表达、标点/体例冲突或跨媒介不一致 |
| `G-ANSWER` 答案唯一性 | 独立作答、第二答案对抗、每个选项与共享题干合成、干扰项失败点、最长答案回填 | 错解、多解、无解、非目标错误干扰项、答案无法写入或版面泄露答案 |
| `G-FACT` 事实时效 | 正文、题干、选项、答案、图片和音视频的事实清单，逐项绑定审校当日权威来源 | 错误、过时、范围夸大、无决定性来源或图文音视频事实冲突 |

`G-FRAME`、`G-BIND`、`G-OFFICIAL` 是容易被内容审校掩盖的结构性红线，必须在语法、难度和美观深审之前关闭。一个门控失败即可把元素记为`需要修改`；后续深审用于补充依据，不得把红线失败改回通过。

### 2.2 三个回归锚点（跨教材通用）

以下案例抽象为强制回查，不是只适用于某一课：

本轮复盘的具体映射为：`P6 1c` → 跨页颜色，`P9 2c` → `word box` 归属，`P10` → `Exam tip` 具体题型。今后遇到不同页码或模块仍执行同一三项检查。

1. **跨页颜色锚点**：先确认题组首题与翻页后续题是否同一视觉角色，再成对比较背景色、容器、编号和作答区。同角色无依据换色即记录问题，即使文字和答案正确。批准的示例区、层级或角色差异可合理保留，不能仅因首题颜色不同就判错。
2. **word box 归属锚点**：逐个把 box 词连到题号、空格和答案，再反向从每个空格追到 box。五道题若与 box 完全无关，或 box 实际属于另一模块，是题块错位/归属错误，不是普通的词汇覆盖不足。
3. **Exam tip 完整性锚点**：标题、tip 和题面构成一个相邻任务容器。tip 至少明确具体题型、题数或选项、作答动作，并与级别/Part 标签一致；只写`Exam tip`或只修改右上角考试名称均不构成修复。

回归锚点必须在报告生成前逐项勾选。无论锚点是否触发错误，都在内部证据清单保留一次记录。

### 事实与时效核查

先建立事实清单，不以“常识”“背景文字”或“不影响做题”为由跳过。把人物、时间、地点、事件、范围、因果和结果拆开验证；传记或历史例子不得把“某次入学考试的部分科目未通过”扩大成“在校考试失败”等更宽断言。

- 可能变化的信息，如机构名称、考试制度、职位、纪录、人口、价格、科技能力、平台功能、法律政策和社会现状，必须查询审校当日的官方或第一方来源并记录核查日期。
- 稳定知识优先使用政府、大学、博物馆、科研机构、标准组织、权威工具书或原始文献；有争议时至少交叉核对两个独立权威来源。
- 区分事实、估计、观点、传闻和教学性简化。估计须注明时间与口径；观点须标明主体；无法证实的名人轶事、智商、纪录或绝对化断言不得保留为事实。
- 图片中的旗帜、地图、建筑、器物、人物身份、文字和时代细节同样属于知识输入，必须与正文及现实一致。
- 教材自身、搜索摘要、百科镜像、营销页和 AI 生成内容不能单独证明事实。没有决定性权威证据时结果不得为 `通过`。

证据至少写明命题、教材位置、来源机构、来源日期或核查日期和结论。最小建议必须保留可核验的限定信息，并避免很快再次过时的写法。

## 3. 严格 Cambridge 英式英语

这是项目加严门槛。Cambridge 考试可接受一致的标准英式或美式英语，但本项目教材自有文字只接受当代标准英式英语，并须符合适用的 Cambridge English 语法、词汇、语域和考试语言规则。核查范围包括正文、标题、题干、选项、答案、例句、释义、图片文字、音视频脚本、提示框和元数据。

判断顺序：Cambridge 官方考试与教学规则 → Cambridge Dictionary/Grammar 的 UK 条目与示例 → Oxford Learner's Dictionaries 的 UK 用法 → 已确认的项目英式体例。多个英式变体都正确时沿用项目体例并保持全书一致；不得把个人偏好写成错误。引用、专名、商标和作品名仅在确属原文时保留来源形式，周边教材语言仍用英式英语。

### 高频差异

| 项目默认英式                                 | 需避免的美式教材自有形式                 | 说明                                 |
| -------------------------------------------- | ---------------------------------------- | ------------------------------------ |
| colour, favourite, behaviour                 | color, favorite, behavior                | `-our`                             |
| centre, theatre                              | center, theater                          | 专名除外                             |
| travelling, traveller；cancelled, cancelling | traveling, traveler；canceled, canceling | 英式常双写`l`                      |
| organise；analyse                            | organize 可属英式；analyze               | 无体例时用`-ise`；`analyse` 固定 |
| defence；licence (n)                         | defense；license (n)                     | `license` 可作英式动词             |
| practise (v)；practice (n)                   | practice (v)                             | 核对词性                             |
| programme                                    | program                                  | 计算机程序用`program`              |
| learnt / learned                             | —                                       | 两者可属英式，内部统一               |

学校语境优先 `head teacher`、`primary/secondary school`、`marks`；生活和交通语境优先自然的 `flat`、`lift`、`lorry`、`holiday`、`timetable`、`postcode`、`mobile phone`、`film`、`football`、`return ticket`、`underground`。这些不是机械禁用表，文化背景和引用按真实语境处理。

同时核对：

- 近期且与现在相关的事件通常优先 present perfect；集合名词按整体/成员语义一致。
- `at the weekend`、`at school`、`in hospital`、`do sport` 等介词和搭配按义项判断；不为“英式感”强加 `have got` 或 `shall`。
- 正文对话无项目体例时优先单引号，嵌套用双引号；serial comma 只在消歧或既定体例中使用。
- 日期优先 `20 August 2026` 或 `20/08/2026`；时间可用 `9.30 am` 或 `9:30 am`，全书统一；标题大小写遵循模块模板。
- 音标采用标准英式读音；多个 UK 读音均有效。音标、词性和所教义项必须一致。
- 逐项核对词典义项、搭配、补语、介词、可数性、词形和语域；“语法上勉强成立”但不符合当代英式自然用法或 Cambridge 教学规则，仍判 `需要修改`。
- 题干和答案采用 Cambridge 常见、清楚、无歧义的考试语言；不得混入美式学校术语、日期时间体例、引号或标点体系。
- 检查相邻句和同段中的无意词语、句式重复及不自然搭配；只有重复影响清晰、自然或教材品质且存在语义、搭配、语域和难度均等值的替换时才建议改写，不能为“避免重复”强换近义词。

证据写明原形式、建议形式、词性或义项及具体 Cambridge/英式规则。有效英式变体之间的差异写“体例不一致”，不写“语言错误”；边界词无可靠证据时标材料/外部证据不足。不得只运行美式拼写词表后即判语言通过。

### 3.1 基本英语逐项必审（全部英文，不限目标词）

每个词条、正文句子、例句、规则、指令、题目、全部选项、答案和图片文字都走完整检查链。词典以具体 UK 词条/义项为证，不能只搜到相同词头就判词性和释义正确。至少保留以下可追溯证据：

| 层次 | 必查对象与做法 | 必须防止的漏检 |
| --- | --- | --- |
| 字符与拼写 | 原样逐词读取，检查漏字、多字、颠倒、粘连/断词、大小写、撇号、连字符、数字/字母混淆和重复词。疑似 OCR 错误回看原页 | `recieve`、`a a`、`l/1` 等不能被自动清理掩盖。`had had` 可能是正确过去完成时，不机械去重 |
| 词形与词性 | 分别记录词头和句中形式，核对复数、三单、过去式/分词、比较级、派生及词性标签。判断其句法功能而非只看后缀 | 不可数名词随意加 s、`friendly` 标 adv、名词与动词同形混淆、`practice/practise` 混用。动名词、分词与词汇形容词按语境分析 |
| 义项与释义 | 词性—UK 读音—英文释义—中文义—搭配—例句同一义项闭合。释义准确、非循环，难度适宜；近义/反义适用范围明确 | 把另一个义项或词性的释义配入当前词条，中文过宽/过窄，例句实际用了别的义项。派生词不是所有格/复数等屈折变化 |
| 句法骨架 | 每句找主语、限定动词及补语，核对主谓、冠词/限定词、可数性、代词、时态语态、助动词后形式、非谓语、从句语序和否定范围 | `She don't ...`、`can to ...`、`where is he` 误作间接问句、重复冠词、残句/逗号粘连；语法错误不因读得懂而通过 |
| 配价与语义 | 核对及物/不及物、宾语数量、介词、动词后 to/-ing、平行结构、修饰对象、逻辑主语和指代 | 如 `depend on` 漏介词；避免规则解释与例句不一致，或“人用-ed、物用-ing”等错误概括 |
| 中英与跨位置 | 中英逐句对应，核对否定、程度、时间、数量、人称和情态强度。核心词/星标/派生表/答案与配套材料按已提供证据双向比对 | 中文看似流畅但漏否定、改语气、错词性；学生用书、知识清单同词异义且无教学说明 |

拼写检查不等于词性审校，词性正确不等于释义正确，释义正确不等于例句正确。逐项判定后再汇总。补充词典证据优先处理疑义、多词性、多义、派生词和 UK 变体；对可确定的基础语法写出具体规则即可，不要求每个普通词都重复联网。

有意设置的错误只在明确的纠错/辨析任务中可保留，并须有唯一修法或唯一正确选项。普通阅读理解选项不能靠偶然拼写、主谓或标点错误泄题。不得因“所有句子应正确”消除本来要考查的错误形式。

词汇覆盖按 lemma + 词性 + 义项 + 输出形式登记。星标词形题须调用已教派生内容，不能仅因词根出现过就证明学过全部派生形式。自然例句可含非目标语言，但关键得分路径不得依赖无教学证据的新规则。

## 4. 答案正确性与唯一性

标准答案题只有在完成以下对抗性验证后才可通过：

1. 不看答案独立作答，记录题面真实限制。
2. 核对预期答案的语言、语义、搭配、事实、逻辑、拼写、大小写、词数和操作。
3. 主动构造第二答案：同义词、英式变体、不同词形、冠词介词、单双数、代词、选项组合或其他图片/文本指代。
4. 为每个干扰项找到必要条件上的明确失败点；“出题人想考它”不是排除理由。
5. 核对题面、答案表、原文、录音、图片和评分说明一致。
6. 将共享题干与每个选项实际拼接成完整句，复核人称、词形、大小写、标点、搭配和语域；非目标性的语法错误不得充当干扰项失败点。

合成检查应区分考点错误与无关错误：考主谓一致时 `He don't ...` 可是有意干扰项，普通阅读题中的同样错误不可泄题。开放性任务不强造唯一答案。听力前置支架还须与后续正式题交叉检查，不能重复考同一答案并提前泄露。

| 题型           | 唯一性最低要求                                   |
| -------------- | ------------------------------------------------ |
| 选择题         | 仅一项完全成立；其余至少一项必要条件失败         |
| 选词填空       | 词库复用规则明确；词形、搭配、语义和篇章共同收束 |
| 开放填空       | 词数和形式明确；语境排除常见同义答案             |
| 词形变化       | 词根、词性、肯否定、单双数和时态唯一确定结果     |
| 匹配/连线/图片 | 每个对象仅一处完整匹配；编号、端点和视觉指向明确 |
| 阅读/听力      | 答案来自规定文本，不以外部常识或图片替代文字证据 |
| 句型转换       | 意义等值；关键词不变；词数合规；答案各部分均必需 |

开放写作和口语可有多种文本答案，但任务目的、受众、体裁、必答点、字数/时长和评价边界必须清楚；示例必须标为示例。无法把标准题收束为唯一答案时，补语境、换干扰项或改成边界明确的开放任务，不能靠答案表补救。

### 4.1 语法点—练习题覆盖与句子建议

显性语法教学必须同时检查“目标 → 练习”和“练习 → 已教目标”两条方向。先从正式目标、`Let's talk!`/规则框、知识清单和对应学生用书建立当课语法点清单，再登记全部语法练习与答案。只有实际要求学生选择或产出、规则正确、答案唯一且能计分的题目才算有效覆盖；仅展示的例句、只阅读的句子、错误题或多解题不算。每个声明点及本课明确教授的必要维度（意义/功能、形式、限制/对比和语境迁移）均须至少有一个有效题目；每道练习不得暗含未教规则。详细拆分、覆盖状态和报告映射见 `grammar-review.md` 的“当课语法点—练习题覆盖审查”。覆盖审查不改变 Cambridge 官方题型、题量或作答动作。

如需修改完整句子，`修改建议`必须同时写出可定位的整句原文和可直接替换的整句，包含完整标点，格式为 `原句：…` 与 `修改后：…`；多句逐句编号。不得只给词语或片段。修改后须保持原意、目标语法、严格英式英语、答案唯一性和 B1—B2 范围；非句子类建议仍用短句。

## 5. 任务闭环、视觉语义与最小建议

### 5.1 任务契约与交叉引用

每个封闭式任务先重建一个“任务契约”，至少记录：题干要求学生处理什么对象、可使用什么材料、执行什么动作、写/选什么单位、完成多少项、示例如何示范、答案如何判定、作答区如何承载。逐项与正文、词库、括号选项、图片、音视频、答案表和页面实际结构比对。`Complete the sentences` 不能对应一段连续文本，`words in the box` 不能对应括号二选一，`underlined/highlighted` 不能只写在题干而页面没有相应视觉状态。

题目中的标题、微标题、提示语、色块和示例必须各自提供新的层级、限制或作答信息。若两处只是重复同一动作、同一标题或同一说明，且删除一处不损失任何任务条件，则记为冗余；不得为保留装饰而制造错误层级。

建立交叉引用图：主题页目标、模块号、题号、标题、体裁、`the text below`、`task in 3b`、音视频、答案和视觉提示均为节点；每条引用必须唯一回指到存在且类型正确的目标。`article`、`story`、`text` 等体裁词必须与真实文本及官方任务一致，编号不能只“看起来接近”。

### 5.2 题干—选项合成与作答模拟

- 选择题、句干补全和表格匹配必须把共享题干与每个选项逐一合成后朗读；检查完整句的语法、大小写、句末标点、语义和语域。句干未结束时不得先放句号，选项不得含与目标考点无关的主谓、词形或句法错误。
- 对每个空格填入最长有效答案，对开放任务执行最长允许响应；检查空格数量、横线长度、括号/斜线位置、换行、表格、分页和书写区是否真实可用。不得把一个预期答案无理由拆成多个空，或让斜线、介词、冠词、关键词和紧密短语孤悬在另一行。
- 版面让答案更容易或更难、改变官方作答动作、暴露词长/词形、无法容纳唯一答案时，属于命题问题而非纯美观问题。

### 5.3 图片的语义证据

图片不仅要“相关”，还要核对学生首先看到的主体、动作、表情、地点和文化线索是否直接表达教学目标。职业、情绪、动作、地点或近义词辨析必须有诊断性特征；装饰主体不能比目标更显眼，每张图片或视觉块都应有独立教学功能。图片参与识词、匹配、推断或回答 `Where is it?` 时，必须把答案唯一收束到目标对象；普通课堂照、泛化惊讶表情或相似古村图不能自动证明具体词义、职业或地点。重复图、无新增信息的视觉块或与目标竞争注意力的素材应判为干扰，不以“符合大主题”为由保留。

### 5.4 样式语义与字符级复核

先建立双向样式—语义矩阵：每种教学角色应使用什么斜体、粗体、颜色、高亮、下划线或标题层级；每种实际样式又代表什么角色。双向检查可同时发现“该强调却漏了”和“非目标内容误强调”。题干声称的视觉状态必须与真实样式一致；作品名、船名等按英式编辑规范和项目体例处理。

再做字符级扫描：数字字形、大小写、空格、撇号、斜线、连字符/短横线/破折号、括号、日期时间、句末标点、符号占位和异常字形。字体形状、`7.00 am`/`7:00 am`、破折号间距等如存在多个有效英式写法，只按批准模板或同模块明确体例报告“体例不一致”，不得伪装成 Cambridge 语言错误。

### 5.5 视觉与版式复核

逐页三轮执行方法及证据字段统一见 `delivery-and-sources.md` 第2节。下面规定判断标准，不以缩略图或纯文本猜测页面效果。

微排版按“原始字符 → 真实页面 → 同角色邻项 → 同模块跨页”复核。连续空格、全角/不换行/零宽字符、Tab、软连字符和手动换行先识别用途。普通英文单词间不应有无意双空格，逗号/句号前不应有无意空格。表格对齐、答案留白、合法不换行空格及 PDF 提取噪声不直接判错。不能只凭文本行尾把正常自动折行判异常。

换行重点为词内断裂、词性标签脱离词条、引号/括号孤悬、标题与正文分离、题干与选项错位、语法公式拆断、答案线断裂，以及仍有可用空间时紧密语义单元被手动拆开。结合字号、栏宽、坐标和原图决定是否需改；不作“冠词和名词任何时候都不得跨行”的绝对规则。

异常粗斜体检查必须同时做漏标与多标：同一词内部局部误加粗/斜体、标点意外继承、标签误斜体、例句整句粗体、同组仅一项样式不同。按教学角色判断，不能用多数票证明正确；若全组都违反批准规则，全组仍需逐元素改。未知样式不能当成普通体，不能只凭字体名称猜最终有效样式。

### 5.6 内部体例及适用边界（2026-08-31 沉淀）

| 适用内容 | 项目体例 | 不得泛化为 |
| --- | --- | --- |
| 普通英文标题 | Sentence case，保留专名、缩写和 I。学生用书模块沿用 `Let's say!`、`Let's talk!` 等正式模板 | 所有单词小写，或把课件 `Let's Say` 强套书面模块 |
| 英文省略号 | 内部非引文默认 `...`，前不加空格，后接新词按词间空格；中文用 `……` | 给未完成选择题句干补省略号。后接问号/括号按句法和引文判断，不照抄反馈中的一概空格 |
| 不完整选择题句干 | 如 `Frank is`，与选项合成完整句，不另加 `...` 或句号；完整问句保留问号 | 所有题干取消标点 |
| 备选项与语法符号 | 备选表达用 `today / tomorrow`，结构记法用 `be + doing`；破折号式对话按 `— Are ...?` 留一空格 | 给 URL、日期、IPA 斜线或正数符号强加空格 |
| 时间 | 项目默认 `9.30 am`，既有有效英式 `9:30 am` 等按已批准模板统一。`10.am` / `4.pm` 不采用，应改 `10 am` / `4 pm` | 把点号写在数字与 am/pm 中间，或声称冒号写法都不是英式英语 |
| 引号 | 默认外单内双，引号内外标点按其语义归属；原文引用忠实 | 将所有句末标点机械移到引号内或外 |
| 知识清单KL06/07词汇例句 | 核心词汇英文例句和阅读原文例句全部不加粗，包括目标词。阅读词条头部的词/短语、词性、中文义按模板加粗 | 推广为KL08语法例句全部禁粗，或将学生用书/小超市例句也取消目标词强调 |
| 知识清单派生表 | noun/verb/adjective/adverb 表头与核心词按模板加粗，每个单元词性与列名一致 | 表头正确即整表正确，或把屈折变化当派生 |
| 学生用书语法 | 语法名称仅粗体，句型粗斜体，点名的具体词斜体，例句目标词粗体（SB13） | 把整句或所有英语斜体、把不同教学角色强行统一 |
| 小超市例句 | 示例中目标词加粗，其余按本模块模板 | 反向覆盖知识清单不加粗的例句体例 |

制作稿绿色高亮等标注意图只用于理解交付要求，不自动成为学生页样式。主题页通常跨页、讨论通常2–3问、Listening/Writing 的日程示例等作为结构诊断提示，不改变适用源行或官方任务。沉淀中的约8空与既有约6题等未确认冲突保留现行正式规则并明确待确认，不私自修改数量标准。

建议必须先识别哪一侧受上位证据约束。图文不一致时先报告冲突和所有受影响位置；只有名称、正文、图片或答案中哪一项明确为准，才指定替换另一项。不得因换图较贵、改字较快或人工反馈采用某种修法，就牺牲事实、官方格式、英式英语、答案唯一性或跨材料一致性。

人工或专业反馈中的替换词、句子、时间格式、字体和版式建议也必须重新核验。先分类为客观错误、已确认内部体例或可选编辑优化；发现拼写错误、不自然搭配、语义改变、难度越界或与 Cambridge 冲突的建议不得原样固化。反馈用于发现漏检机制，不作为替代上位证据的答案表。

### 5.7 专家反馈的校准与闭环

专家反馈用于发现审校盲区和高价值核查路径，不是自动判错标签，也不是可直接粘贴的标准答案。每条反馈在维护复盘或软件工作流中保留来源文件、段落/表格/图像定位、涉及教材元素、观察到的问题、建议、适用边界、裁决状态和依据。不得把多条针对同一页的意见压成一个无法回溯的“专家已审”。

裁决状态至少区分：`confirmed`（原稿问题有证据）、`adopted_with_scope`（抽象出的机制成立，但仅在明确条件下使用）、`optional`（可选优化，不作为错误）、`dismissed`（建议不正确或与上位规则冲突）和 `unresolved`（缺原页、模板、上下文或权威证据）。未决建议不能计作通过或需要修改；只有确认的材料错误进入“需要修改”。

逐条核实建议文本本身：字符/拼写 → 词形与词性 → 义项/释义 → 句法 → 搭配与语域 → 中英对应 → 目标范围和难度 → 题目答案及唯一性 → 事实/来源 → 页面和样式。涉及替换句或段落时，对建议全文重新执行检查，并回看相邻句、对应题目、答案、交叉引用和视觉提示；专家身份不能豁免复核。比如反馈建议中的 `purse` 若表达“追求职业”，须核实为 `pursue`，不能照录错拼。

任务与页面按一条语义链核对：学习目标 → 模块/题型标签 → 学生实际动作和答案单位 → 材料/词库/图片/音视频 → 预期答案与答案表 → 反馈/示例 → 作答区和页面呈现。任何一环变化，都回查其上下游依赖。指令应说清真实动作和答案单位（如括号内选词、一个词或短语），不能仅因反馈提供了更完整的句子就接受；建议指令必须与实际题面逐项相符。

视觉修改也需按语义链裁决：先确认教学目标要求学生看到的诊断性特征，再核对图像主体/动作/表情/地点、与题文答案的绑定、裁切/缩放/比例、邻近文字和作答区，最后复看实际渲染页。主题相似不等于目标语义成立；图片不得拉伸变形、切掉关键特征、遮挡文字或挤压任务。必要的换图、裁图和重排建议须以目标证据和实际效果为准。

空格、标点、大小写、引号、斜线、粗体/斜体/高亮和对齐意见先判断文本角色与教学角色，再与批准模板、同模块/跨页同角色元素对照。完整句、标题、词条、短语、公式、引文和未完成题干的标点规则不同；例如个别反馈提出“居中省略号”或删除句点，只能作为待核候选，不能升级为全局规则。可选美化不得覆盖可读性、语言正确性、官方作答动作或答案唯一性。

把个案意见推广为通用规则前，先说明可迁移的不变量、触发条件、反例/不适用边界及其与 review list、批准模板和上位标准的关系。单条“待修改”、设计师确认请求、成本/排期考量或局部版面偏好都不足以建立通用禁令；遇到冲突，保留待裁决状态并记录所缺证据，不猜测专家意图。

## 6. B1—B2 全范围难度

### 六类结果

- `B1 核心`：典型 B1 能力足以完成关键作答路径。
- `B1 较高负荷`：仍可由 B1 完成，但至少一维接近 B1 上沿。
- `B2 基础`：至少一个必要要求调用 B2 能力，整体负荷位于 B2 基础至中段。
- `B2 较高负荷`：多项必要要求稳定调用 B2 能力，或接近 B2 上沿，但不依赖 C1 能力。
- `超出 B2 上限`：关键作答路径必须依赖 C1 或更高能力。
- `证据不足`：无法重建关键作答路径。

`B2 基础` 和 `B2 较高负荷` 是项目内部校准标签，不对应 Cambridge 单题分数或考试 Grade。B2 上段仍属合理范围；负荷高、文本长或 I3 较多本身不构成越界。

先回答：学生要理解/产出什么；证据在哪里；需几步转换；哪些语言或背景知识不可绕过；作答时有哪些真实支架；去掉偶发最难特征后等级是否改变。只给决定成败的负荷计权。

| --------- | ------------------------------ | ---------------------------- | -------------------------------------------- | -------------------------------------------------------------------- | ---------------------------------------------------- |

| 干扰项    | 明显不符或无关                 | 局部匹配但一处清楚失败       | 复用原文但改变关系、指代、结论或态度         | 多项表面合理，需结合跨句或跨段证据排除，区别仍有明确依据             | 主要靠极细微语体、修辞或立场差异排除                 |
| 认知      | 识别、提取、简单分类           | 多条件匹配、清楚因果或顺序   | 比较、解释、评价、较完整论证                 | 综合多点信息、权衡观点或利弊、处理具体与抽象议题                     | 高度抽象评价、专业推理或原创性多源综合不可绕过       |
| 输出/支架 | 控制练习、短线性产出、支架充分 | 支架减少、段落或解释增加     | 较独立比较、解释或论证                       | 清楚详细的多段产出；能展开观点、比较利弊并使用较丰富结构             | 要求 C1 式精确语体、灵活含蓄表达或复杂多源长篇综合   |

信息获取辅助码：`I0` 原词/同句；`I1` 单句释义或明确因果；`I2` 跨句指代、时间、逻辑整合；`I3` 跨段、态度、隐含义或多源扫描。B1 以 I0–I1 为主，可有支架化 I2；B2 基础可稳定要求 I2、适量 I3；B2 较高负荷可多次要求 I3，只要证据链仍可回溯。I3 数量不能单独判越界；只有与 C1 式语言、隐含程度、综合要求或低支架叠加并决定成败时，才判 `超出 B2 上限`。

B1 接收以熟悉主题、直接事实、清晰标准语和线性主线为主；产出以描述、叙事、个人观点和简单理由为主。B2 全范围可要求理解具体或抽象主题的复杂文本、跟踪立场和论证、较自然地互动，并清楚详细地比较、解释、评价和展开观点。只有任务必须依赖 C1 式的隐性意义识别、宽泛习语掌握、精确灵活语体或复杂多源综合时才越界。

句长、复杂句比例、文本长度、单个生词、词表外比例或题型名称均不能独立定级。

## 7. Cambridge 题型基准

仅在材料声称 Exam tip、真题、模拟题或具体 Part 时应用。正式名称为 `B1 Preliminary for Schools` 和 `B2 First for Schools`；for Schools 与成人版等级、结构相同，主题更贴近学生。B2 First 成绩 160–172 为 Grade C（CEFR B2）、173–179 为 Grade B、180–190 为 Grade A（CEFR C1）；这是整套考试结果，不是单题标签。

### B1 Preliminary for Schools

- Reading：45 分钟，6 Parts，32题：P1短文本三选一5；P2人物需求与8短文匹配5；P3长文四选一5；P4句子还原5；P5四选一完形6；P6一词开放填空6。
- Writing：45 分钟。P1约100词邮件；P2 article/story 二选一，约100词。
- Listening：约30分钟，25题，录音两遍：P1图片三选一7；P2短对话三选一6；P3独白填空6；P4访谈三选一6。
- Speaking：P1 interview，约2分钟；P2每人约1分钟照片描述；P3建议讨论与协商；P4熟悉话题交流。

### B2 First for Schools

- Reading and Use of English：1小时15分钟，7 Parts，52题，总阅读量约2,200–2,500词：P1四选一完形8；P2一词开放填空8；P3词形变化8；P4关键词转换6（2–5词、关键词不变、每题最多2分）；P5四选一阅读6；P6句子还原6；P7多项匹配10。
- Writing：1小时20分钟，两篇各140–190词。P1必答 essay；P2三个任务选一（Questions 2–4），for Schools 体裁可含 article、email/letter、review、story，体裁类别不等于当次选项数量。`report` 属成人版，`story` 属 for Schools。现行 handbook 不再包含 set-text 选项。
- Listening：约40分钟，30题，录音两遍：P1短录音三选一8；P2独白填空10（不超过3词、无需变形）；P3五段独白与8陈述匹配5；P4访谈/对话三选一7。
- Speaking：P1 interview；P2每人比较两图1分钟，并回应同伴问题约30秒；P3讨论2分钟、决策1分钟；P4延伸讨论。

凡使用 Cambridge 考试名称、paper/Part 名称、官方标识或“真题/模拟题”定位，均须匹配该 Part 的题型、选项数、题数、字数、作答动作、技能和关键版式。题量不足时判 `需要修改`，不得仅把题干数字改小；若只做孤立技能练习，则不得把它标成完整官方 Part。真题要有可核验出处，自编内容称“模拟题”。官方开放填空可能接受备选答案，本项目仍要求标准题唯一；无法收束时改为开放任务。严禁用 Cambridge 可接受美式英语来覆盖项目的英式英语门槛。

## 8. 难度递进与记录

在题组、模块和课次内检查真实负荷：基础含义 → 分类/逻辑 → 词形或语境；同句定位 → 改写 → 跨句/跨段；支架逐步减少、输出逐步增加。顺序数字增加但负荷不增仍属于平台。

难度证据至少写：任务要求、证据位置、信息获取层级、必要语言/认知负荷、真实支架和最终标签。其他证据均写具体位置、对象、事实和规则；只给最小修改建议。
