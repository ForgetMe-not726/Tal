# AI 修改建议与本地检索助手契约

> 状态：**Module 修改建议助手的 Context Pack 已落地（2026-10-09）**——七部分齐、规则作为
> 参考知识库进 Pack、来源定位可「查看原页」、缺口如实列出。**通用助手（§4 的自然语言检索 adapter）
> 仍待本地检索工具代码（Q-CORE-016）**；本地目前也没有 Cambridge 参考资料（Q-CORE-030）。
> 上位文档：profile.md V1.2。若本文与 profile.md 冲突，以 profile.md 为准。

## 1. 两类能力必须分开

### Module 修改建议助手

位于“教材制作”页，作用域固定为老师当前打开的 Module。它可以根据自然语言要求生成修改建议，但不能自动保存、确认或发布内容。

### 通用助手

位于主页，用于跨本地资料查找知识点和查看来源证据。它默认只读，不能把检索结果直接写入教材或规则。

两者可以共享检索 adapter 和证据格式，但必须使用不同命令、权限和界面，避免一次通用问答意外变成教材写入操作。

## 2. 最小 Context Pack

修改建议助手每次请求只组装当前任务必要的 Context Pack：

~~~text
teacher_request
current_module_version
lesson_context
effective_rules
relevant_cross_book_context
retrieved_cambridge_evidence
known_gaps
~~~

规则压缩不是普通摘要。每条生效规则必须保留：规则 ID、作用域、Hard/Soft、机器约束、优先级关系和冲突状态。与当前 Module 无关的规则不得进入请求。

Cambridge 资料通过本地检索按需加入。每个片段必须携带可显示的来源定位；无法确认出处的内容不能伪装成 Cambridge 依据。整本 PDF 不进入单次模型上下文。

Context Pack 属于任务临时产物，可记录在 `.app/jobs` 便于诊断，但不能成为正文或规则的唯一事实源。

## 3. 修改建议输出

每条建议至少包含：

- 建议 ID 与修改类型；
- 当前 Module Version；
- 原文范围；
- 建议文本或操作；
- 修改理由；
- 触发的规则 ID；
- Cambridge 或其他本地来源证据；
- 不确定性和资料缺口；
- 待处理、已采用或已忽略状态。

老师点击“采用建议”后，建议内容进入当前草稿并以差异形式显示；只有再次保存才创建新 Module Version。一次采用不得静默修改其他书种。跨书影响只能生成新的同步建议。

## 4. 本地检索 adapter

后续提供的本地检索工具通过 adapter 暴露稳定能力，业务层不依赖其索引文件、数据库或内部类名。

最小查询输入：

- 自然语言查询；
- 项目或全工作区范围；
- 可选的书种、Lesson、Module、来源类型过滤；
- 返回数量与是否需要页图证据。

最小查询结果：

- 命中文本和必要上下文；
- 来源文件稳定引用；
- 书名、Lesson、Module、页码；
- 块 ID 与页内坐标（如可用）；
- 来源状态：待核对或已确认；
- 对应页图或可生成截图的定位；
- 检索分数仅作排序提示，不作为正确性结论。

adapter 必须能在替换检索实现后保持上述契约不变。本地索引可删除并由原始文件、OCR 结构和 manifest 重建。

## 5. 原书 PDF 证据

“查看原页”优先显示 OCR 保存的页图，并按块坐标高亮命中区域。若只有页码没有坐标，则显示整页并标注“仅定位到页”；若连页码也没有，则结果不能显示为精确命中。

截图是来源证据的视图，不创建第二份教材内容。应用应从原文件和 OCR 页图生成预览缓存，缓存可删除、可重建。

## 6. 失败与不足

- 没有命中：明确显示“未在当前本地资料中找到”，并给出已搜索范围；
- 命中冲突：并列显示不同来源，不由模型擅自裁决；
- 来源未确认：可供老师查看，但不能作为 Production Source 参与生成；
- 资料不足：修改建议标记不确定性，不使用模型常识冒充本地规则或 Cambridge 内容；
- 页图缺失：保留文字定位并提示重新处理来源，不伪造截图。

## 7. 验证标准

- 查询结果可返回到正确文件、页码和页图；
- 同名 Lesson、Module 或词汇不会串到错误项目；
- 修改建议只使用当前 Module 和明确检索到的上下文；
- Hard Rule 在压缩后仍完整、可识别且不可被低层规则覆盖；
- 通用助手没有教材写入入口；
- 采用建议生成新版本，原版本保持不变；
- 更换检索工具后，产品界面与业务数据无需理解新的内部索引格式。

本地检索工具代码未提供前，只实现或评审 adapter 契约，不虚构其具体能力和性能。
