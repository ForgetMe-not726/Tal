# 练习册迁移与制作规则（可导入版 · 初拟）

> **状态：初拟，未经需求方与教研最终确认。同步基线：profile.md V1.2，2026-09-23。** 本文件的目标用途是经老师复核后，通过本地规则导入流程写入工作区 `rules/` 目录；导入并发布后才参与生成。
>
> 导入前请确认两件事：
> 1. 规则内容确实是本项目要执行的正式规则；
> 2. 每条规则的 `R-WB-*` 标识、显示名和机器约束没有需要调整的地方。
>
> **主要依据**：新版审校清单 `26教材list-5A.xlsx` 的「练习册」工作表（权威度最高）、新版成稿样本 `新版内容/Lesson 13  An open mind练习册在线文档.docx`、旧版 `寒假练习册` MinerU OCR。
>
> **产品级红线不在此重复定义。** 来源人工核验、来源标注、显式映射、课时映射、目标术语 `Lesson`、规则版本与 Mock/placeholder 排除等共通约束，应从知识清单候选规则中提炼为本地 Global 规则；本文件只写**练习册特有**的内容规则。
>
> **两类规则必须分开（2026-09-23 边界决定）：**
> - **迁移结构规则**（`类型：普通规则（生成）`）——描述旧版内容该搬到哪个板块、怎么组织。
>   迁移阶段要执行的是这一类。
> - **新版要求规则**（`类型：审校规则`）——来自新版审校清单，描述**新版成品应该长什么样**。
>   旧版教材自然满足不了它们，**迁移阶段不该用它们约束生成**（否则会逼模型编造旧版没有的内容）。
>   它们是后续「AI 修改建议」功能的红线来源。完整清单见 `docs/drafts/新版要求-审校清单-提取.md`。
>
> 机器约束只使用当前确定性检查器已实现的字段：`min_words` / `max_words`、`banned_words`、`required_sections`（+`required_sections_ordered`）、`require_confirmed_source`、`require_source_annotation`、`require_annotation_in_text`。其余检查意图写在「指令」里进入生成 Prompt，**不会被执行**；确实需要落地的，在条目下用「说明」标出需要新增哪个检查器。

## R-WB-001 目标模块完整性与顺序

- **类型**：普通规则（生成）
- **指令**：练习册每一课按 `Day 1` → `Day 2` → `Day 3` → `Day 4` → `Day 5` 五个板块组织，顺序固定，不得增删板块。练习册**没有** `Let's explore!` 板块。每个 Day 必须输出完整题目，不得只给标题或占位。

```json
{}
```

说明：模块顺序由模块目录（`lib/modules/directory.ts` 的 `day_1`–`day_5`）保证，不使用 `required_sections` 约束——该约束按标题字面匹配，而生成是逐模块进行的，用全局章节清单检查会误报。

**复习课（Lesson 7 / 秋季 Lesson 15）的补充说明（2026-09-28）**：上面的「每一课按 Day 1–5」包含复习课，但**题源与常规课不同**——
旧版复习单元（`# Unit 7`）是整课复习，只有 `## ① …`–`## ⑤ …` 编号题、**没有 `Hello X` 栏目名**，因此：

- 解析器把这五道编号题统一归到 `revision` 键，**不判断哪道是词汇、哪道是语法**——那是语义判断，交给模型按骨架分；
- 复习课的 `Day 1` 取 `revision` 做词汇+语法复习（`① ②` → `## Let's say!`、`③` → `## Let's talk!`），`Day 5` 取 `revision` 做写作复习（`④ ⑤`）；
- `Day 2` / `Day 3` / `Day 4` 与常规课一致：旧版没有对应内容，留空待教研用 AI 建议补充。

模块目录里由 `revisionSourceSections` 与 `revisionOutline` 表达这两处差异（常规课的 `sourceSections` 一律不含 `revision`，
所以复习材料不会混进常规课正文）。**待确认**：新版练习册复习课是否真的含 `Day 4`、是否要把六个单元的 `Hello Revision` 也并进来（见 question.md Q-WB-009 / Q-WB-011）。

## R-WB-002 题目基于学生用书，考点一一对应（Hard）

- **类型**：Hard Rule
- **指令**：练习册的所有题目都基于学生用书，考点必须与学生用书一一对应，**不得超出学生用书范围**。生成时必须以本课已确认的学生用书版本为准，不得凭模型知识补充学生用书未出现的词汇、语法点或题型。学生用书尚未确认的课次，不得声称练习册题目与学生用书一致。

```json
{
  "require_confirmed_source": true,
  "require_source_annotation": true
}
```

说明：需要新增「跨书一致性检查器」——比对练习册题目涉及的词汇与语法点是否都在本课学生用书中出现过。当前只有来源确认与来源标注是确定性的。

语法题型根据语法点灵活选取：判断题、情景选择题、括号内二选一（不填空版）、选词填空、改错。

## R-WB-009 答案不进入正文（Hard）

- **类型**：Hard Rule
- **指令**：除 R-WB-008 规定的示例之外，练习册正文**不得包含任何答案**：不写参考答案、不写答案页、不在题后附答案。旧版材料里以「参考答案请勿录入：」「答案请勿录入：」起头的内容、以及标注为答案的段落，一律不得进入正文。答案由排版与教师用书单独处理。

```json
{
  "banned_words": ["参考答案", "答案请勿录入", "参考答案请勿录入", "答案：", "答案:"]
}
```

说明：`banned_words` 是全文子串匹配，会连带拦下 R-WB-008 要求的示例答案。**启用本条前需要新增「排除示例块后再匹配」的检查器**，否则会与 R-WB-008 冲突。
