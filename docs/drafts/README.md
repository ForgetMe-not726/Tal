# 教材规则与映射草稿说明

> 同步基线：profile.md V1.2，2026-09-22。此目录中的 Markdown 均为未确认草稿，不是已发布规则。

## 当前用途

- `规则库导入-*`：供老师复核后导入本地规则目录的候选规则包；导入前必须确认范围和约束。
- `规则文件-*`：比可导入版更完整的规则依据和 schema 设计草稿。
- `迁移对应关系-*`：定义通用映射方法，不保存某个学期的实际映射事实。
- `知识-数据-规则系统-方案.md`：本地文件工作区下的知识、数据与规则边界。
- `_refs/`：样本、表格和旧教材的文本摘录，只作证据，不参与自动发布。

## 统一边界

1. 所有正式数据写入老师本地工作区，不写入 Supabase、PostgreSQL 或公司远程知识库。
2. 草稿通过本地规则导入流程形成项目规则副本；未经老师确认不得进入 Published 规则集。
3. 旧版来源中的 `Unit` 可以作为原文保留；新版目标、界面和报告统一使用 `Lesson`。
4. 原始摘录、OCR 结果和样本不能直接成为 Production Source；老师确认后才可参与制作和审校。
5. 草稿中的旧原型代码路径仅帮助迁移实现，不代表正式桌面运行时架构。
6. 具体教材规则等待新版大纲和教研确认；未决内容统一写入根目录 `question.md`。
