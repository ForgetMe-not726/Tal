## 1. 新版目标结构（从成稿样本归纳）

### 1.1 单课模块

新版学生用书每一课的结构是固定的，模块名称统一为 `Let's X!`：

```text
课时目标（In this lesson, we will...）——不属于任何 Let's 模块
    ↓
Let's explore!   1a
    ↓
Let's say!       2a → 2b →〔Develop Your Vocabulary〕→ 2c
    ↓
Let's read!      3a → 3b →〔SKILLS〕→ 3c
    ↓
Let's talk!      〔语法标题〕→ 4a → 4b → 4c〔→ 4d〕
    ↓
Let's use!       〔Cambridge 页眉 + Exam tip + 题型框〕→ 5a〔→ 5b → 5c〕
```

**复习课**（Lesson 10、15「Fun with review」）只有三个模块，小节编号整体前移，课时目标也少一条（没有阅读，因为不含 Let's read!）：

```text
课时目标（三条：复习词汇 / 复习语法 / 练习考试技能）
    ↓
Let's say!       1a → 1b → 1c        复习前几课词汇
    ↓
Let's talk!      2a → 2b → 2c        复习前几课语法
    ↓
Let's use!       〔Exam tip〕→ 3a → 3b → 3c → 3d → 3e
```

核对结果（L9/L11/L12/L13/L14 常规课，L10/L15 复习课）：

| 课 | explore | say | read | talk | use |
|---|---|---|---|---|---|
| L9 | 1a | 2a 2b 2c | 3a 3b SKILLS 3c | 4a 4b 4c | 5a |
| L11 | 1a | 2a 2b DvV 2c | 3a 3b SKILLS 3c | 4a 4b 4c 4d | 5a |
| L12 | 1a | 2a 2b 2c | 3a 3b SKILLS | 4a 4b 4c | 5a |
| L13 | 1a | 2a 2b 2c | 3a 3b SKILLS 3c | 4a 4b 4c | 5a |
| L14 | 1a | 2a 2b 2c | 3a SKILLS 3b 3c | 4a 4b 4c | 5a 5b 5c |
| L10 | — | 1a 1b 1c | — | 2a 2b 2c | 3a 3b 3c 3d 3e |
| L15 | — | 1a 1b 1c | — | 2a 2b 2c | 3a 3b 3c 3d 3e |

结论：**模块集合与小节编号是稳定的，模块内的字母数量可随课变化。**

## 2. 新版审校清单给出的逐模块细节要求

以下摘自 `26教材list-5A.xlsx`「学生用书」工作表，是**新版细节要求的正式口径**，生成时按此执行。

### 2.1 主题页

```text
In this lesson, we will...
learn words...,
read the article...,
learn the grammar of...,
listen to a...
```

四条依次对应：主题词汇 / 阅读文章 / 核心语法 / 考试技能训练。第 4 条随本课题型变化（成稿里出现过 `listen to a...` 与 `practise the use of...` 两种写法）。

### 2.2 Let's explore!

`1a Did you know...`——课文前导短文，**包含本课所有核心词汇**。

### 2.3 Let's say!

- `2a`：主要形式为小短文，**包含本单元的核心词汇**，通常使用加粗或高亮形式呈现。
- `2b`：根据英文释义和句子上下文，从 word box 中选择单词进行匹配。
- `2c`：选用每单元**标星词**进行原型与派生词二选一。
- 单词无遗漏，拼写与大小写无误；图片符合单词教学点。
- 题目要求：考全（所有单词必须考到一遍）、正确性、难度梯度（由简单到难）、不超纲、答案唯一、答案分布不集中。

### 2.4 Let's read!

- `3a`：阅读前导入（讨论题）。
- `3b`：阅读文章，难度相对暑假整体下调，题型基本为**句子挖空和单项选择**，并附阅读技能（SKILLS）讲解框。
- `3c`：**开放观点题，2 道左右**。
- 题目必须从原文找到定位，不能通过图片得出；SKILLS 模块与本课阅读题目相关，**讲解加练习**。
- 话泡与说话人对应，气泡顺序从上到下、从左到右，不遮挡人物。

### 2.5 Let's talk!

- `4a`：基础语法规则填空或识别，特殊用法放入 **LOOK 提示框**。
- `4b`、`4c`：语法知识巩固（单选、变形、选词等）。
- `4d`：综合语法运用（对话、短文或句子内的变形填空）。
- 每个部分的题量在 **5 题左右**。
- 格式规则：语法点只加粗；句型加粗并加斜体；规则讲解中提到的具体单词加斜体；例句中的目标关键词加粗；**例句左对齐**。
- 语法内容量与难度相对暑假缩减。

### 2.6 Let's use!

- `5a`：Exam tip（**如果该题型已经出现过就不再提供说明**）+ 剑桥 FCE/PET 原题或模拟题实战。
- 听力、阅读和语用模块题量在 5 个左右。
- 难度保持在 **B1**，题型为 FCE 相关或与本课话题相关，「一定不能太难」。

### 2.7 书级信息

- 二维码名字：`26秋下-学生用书-第X课`。
- 页脚：页码与序号顺次，且不能被图片遮盖。
- 封面：季节、名称 `Student's Book`、层级 `LEVEL 5`。
- 目录：标题按大纲核对完整（拼写、大小写、标点），页码无遗漏且顺序正确。
- 附录：附录单词按**大纲**核对完整。

### 2.8 通用大原则

- 单词拼写、语法句子一律用**英式英语**。
- 单元封面、页面配图：符合脚本文字或课次主题；不出现负面元素；Let's read! 里的图片，人物数量与类型须与文章内容一一对应。

## 3. 旧版栏目盘点（同一本旧书内部并不一致）

旧版每课的栏目集合**并不统一**，这是本次迁移最主要的结构差异来源：

| 旧版 Unit | 实际包含的栏目 |
|---|---|
| Unit 1 Fond memories | I can / Did you know…? / **Hello World** / Hello Vocabulary / Hello Reading / Hello Grammar / Hello Use of English |
| Unit 3 In harmony with nature | I can / Did you know…? / Hello World / Hello Vocabulary / Hello Reading / Hello Grammar / **Hello Use of English** |
| Unit 6 The best we can be | I can / Did you know…? / Hello Vocabulary / Develop Your Vocabulary / **Hello Listening** / Hello Grammar / **Hello Speaking** / **Hello Writing** / Vocabulary Revision / Grammar Revision |
| Unit 7 Revision | 整课为复习 |

此外 Unit 6 之后还附 `Reading Practice` / `Listening Practice` / `Speaking Practice`，作为备考练习。

> **勘误（2026-09-24，按 OCR 实测修正）**：上面这五个栏目
> （`Vocabulary Revision` / `Grammar Revision` / `Reading Practice` / `Listening Practice` /
> `Speaking Practice`）**属于复习单元（目录页写作 `Unit 7 Revision 112`），不属于 Unit 6**。
> 依据有三：
> 1. 目录页把 Unit 7 列为独立单元；
> 2. 内容是**跨单元**复习（「Match the sentence halves 1–12」「Find six question tags that are wrong」），
>    不是 Unit 6 自身主题（友谊）的练习；
> 3. 旧版 OCR 里复习单元**没有单元标题**，所以它整块跟在 Unit 6 后面，容易被误读成 Unit 6 的附属栏目。
>
> 部门大纲也印证了这一点：Lesson 5（原 Unit 6）的「阅读」是**空的**，它本来就不该有阅读；
> 而早先把 `Reading Practice` 记成 `read` 时，Lesson 5 的 `Let's read!` 会拿到复习单元的
> `Sophie's passion for apps` 当课文。
>
> **已实现的处置（2026-09-24）**：复习单元在解析器里成为**独立的一讲**（正文里没有
> `UNIT 7` 标题，由 `Vocabulary Revision` 兜底作课边界，见 `lib/knowledge/legacy-student-book.ts`），
> 五个栏目按常规键归位——`Vocabulary Revision` → say、`Grammar Revision` → talk、
> `Reading Practice` → read、`Listening/Speaking Practice` → use。这样**复习课**的三个模块
> 直接用 `sourceSections` 就能取到题源，不需要新的栏目键，也不会串进常规单元。

**结论：不能按“旧版有哪些栏目”推导新版模块集合。** 目标模块只由新版模板决定（见 §1.1），旧版多出来的栏目按 §4 归入对应模块，不新开模块。

## 4. 模块级对应关系

### 4.1 通用映射

| 旧版来源块 | 新版目标模块 | 默认动作 | 对应方式与边界 |
|---|---|---|---|
| `Did you know…?` + `Hello World` 主题短文 | `Let's explore!`（1a） | `ADAPT` | 同为话题引入的科普短文；需按本课主题重写，不得整段照搬他课 |
| `Hello Vocabulary`（词汇表、定义匹配、选词填空） | `Let's say!`（2a 2b 2c） | `ADAPT` | 词条内容以确认来源为准，题型按新版骨架重排 |
| `Develop Your Vocabulary` | `Let's say! → Develop Your Vocabulary` | `ADAPT` | 词汇拓展知识块，位置在 2b 与 2c 之间 |
| `Vocabulary Revision` | **复习课**的 `Let's say!` | `ADAPT` | 属复习单元，是复习课的题源；不并入常规单元。见 §3 勘误 |
| `Hello Reading`（文章 + 题目 + Exam tip） | `Let's read!`（3a 3b SKILLS 3c） | `ADAPT` | 文章保留；Exam tip 改写为 SKILLS 技能框 |
| `Reading Practice` | **复习课**的阅读题源 | `ADAPT` | 属复习单元；复习课不含 `Let's read!`，只作题源。见 §3 勘误 |
| `Hello Grammar`（语法讲解 + 表格 + 练习） | `Let's talk!`（4a 4b 4c） | `ADAPT` | 语法点、表格、例句优先承接，按新版骨架重排 |
| `Grammar Revision` | **复习课**的 `Let's talk!` | `ADAPT` | 属复习单元，是复习课的题源；不并入常规单元。见 §3 勘误 |
| `Hello Use of English`（讨论 + 短文 + 完形 + Exam information） | `Let's use!`（5a） | `ADAPT` | Exam information 改写为 Exam tip；短文与题目按题型的规范体例重排 |
| `Hello Listening`（音频题 + Exam tip） | `Let's use!` | `ADAPT` | 新版不再单设听力栏目，听力题型并入本模块 |
| `Hello Speaking`（照片比较 + 功能句框） | `Let's use!` | `ADAPT` | 同上，口语题型并入本模块 |
| `Hello Writing`（范文 + 要点 + Exam tip） | `Let's use!` | `ADAPT` | 同上，写作题型并入本模块 |
| `Listening Practice` / `Speaking Practice` | **复习课**的 `Let's use!` | `ADAPT` | 属复习单元，是复习课的题源。见 §3 勘误 |
| `I can`（本课能做到） | 课时目标（`In this lesson, we will...`） | `ADAPT` | 五条能力描述改写为四条（常规课）：主题词汇 / 阅读文章 / 核心语法 / 考试技能 |
| —（旧版没有） | `Appendix: Words & Expressions` | `GENERATE` | 书级栏目，词条取自本课核心词汇；词性与等级需有确认来源 |
| 整课 `Revision`（Unit 7） | 复习课（`Fun with review` 结构） | `ADAPT` | 已确认生成（question.md A-011）：三个模块 say/talk/use，小节从 `1a` 起；课时目标三条固定句式，不取大纲字段；旧版整课复习材料**只作题源**，按新结构重排 |

旧版块与新版模块可以一对一、一对多或多对一。**任何关系都必须写入显式 `ModuleMapping`**；上表的默认动作不能替代实际映射记录。

### 4.2 五条关键结构变化

1. **栏目集体改名**：Hello World/Did you know → `Let's explore!`；Hello Vocabulary → `Let's say!`；Hello Reading → `Let's read!`；Hello Grammar → `Let's talk!`；Hello Use of English / Listening / Speaking / Writing → `Let's use!`。
2. **模块集合固定化**：旧版每课栏目不同，新版统一为 5 个（复习课 3 个）。
3. **新增课时目标**：每课开头 `In this lesson, we will...`，四条短句，旧版 `I can` 是它的前身但条数与措辞不同。
4. **新增考试题型的显式包装**：`Let's use!` 增加了三样旧版没有的东西——`Cambridge English Qualification | <考试名>` 页眉、`Exam tip` 框、`<考试> <Paper> Part N` 题型框。
5. **新增 SKILLS 技能框**：阅读技能从旧版的 `Exam tip`（一段英文提示）改造成结构化的技能块，含技能名与解题方法。

## 5. 小节级对应关系

### 5.1 Let's say!（词汇模块）

| 新版小节 | 内容 | 旧版来源 | 动作 |
|---|---|---|---|
| 2a | 一段含本单元**核心词汇**的小短文，目标词以**加粗或高亮**呈现；题面为“读短文，从语境猜目标词的含义” | 旧版 `Hello Vocabulary` 的 2a（leaflet / 短文） | `ADAPT` |
| 2b | 按英文释义与句子上下文，从 word box 中选词进行匹配（可分组） | 旧版 2b（词义匹配、选词填空） | `ADAPT` |
| Develop Your Vocabulary | 词汇拓展知识块（如 Words with multiple meanings、Verbs ending in -en） | 旧版同名栏目 | `COPY` / `ADAPT` |
| 2c | **原型与派生词二选一**，只使用本单元的**标星词**（如 `(admission / admit)`） | 旧版 `Hello Vocabulary` 的最后一题 | `ADAPT` |

**关键约束**：2a 短文的词表必须与大纲核心词汇完全一致——漏词或多词都是不合格。标星词的选词标准尚未提供，确认前不得自动加星（见 question.md Q-SB-010）。

### 5.2 Let's read!（阅读模块）

| 新版小节 | 内容 | 旧版来源 | 动作 |
|---|---|---|---|
| 3a | 阅读前导入（讨论题或看图预测） | 旧版 `Hello Reading` 的 a | `COPY` / `ADAPT` |
| 3b | 阅读文章（标题 + 正文，保留原文），并附阅读技能 SKILLS 讲解框；题面以**句子挖空和单项选择**为主 | 旧版 `Hello Reading` 的文章与题目 | `COPY` / `ADAPT` |
| SKILLS | 技能框：技能名 + 解题方法讲解 + 配套练习 | 旧版 `Exam tip` | `ADAPT` |
| 3c | **开放观点题，约 2 道** | 旧版 `Hello Reading` 的题目 | `ADAPT` |

**关键约束**：文章原文在迁移后保持不变；题目必须能从原文找到定位，不能靠图片得出。

说明：按审校清单，`3c` 是开放观点题，而选择题在 `3b`。成稿样本 Lesson 9 把选择题放在 `3c`——两者不一致，已记入 question.md Q-SB-008，确认前按审校清单执行。

### 5.3 Let's talk!（语法模块）

| 新版小节 | 内容 | 旧版来源 | 动作 |
|---|---|---|---|
| 语法标题 + 说明 + 结构表格 | 语法点名、用法说明段、时态/结构/用法/例句对照表 | 旧版 `Hello Grammar` 的讲解与表格 | `COPY` / `ADAPT` |
| 4a | 基础语法规则填空或识别，特殊用法放入 **LOOK 提示框** | 旧版语法练习 | `ADAPT` |
| 4b / 4c | 语法知识巩固（单选、变形、选词等） | 旧版语法练习 | `ADAPT` |
| 4d | 综合语法运用（对话、短文或句子内的变形填空） | 旧版语法练习 | `ADAPT` |

**关键约束**：语法点由大纲「语法知识点」列决定；一课可以有两组语法（如 L11 的 present / past 两段）；**每个部分题量 5 题左右**；内容量与难度相对暑假缩减。格式规则见 §2.5（语法点只加粗、句型加粗加斜体、例句关键词加粗且左对齐）。

### 5.4 Let's use!（考试技能模块）

| 新版小节 | 内容 | 旧版来源 | 动作 |
|---|---|---|---|
| Cambridge 页眉 | `Cambridge English Qualification` + 考试名（如 B2 First） | 旧版 `Exam information` 里提到的考试名 | `ADAPT` |
| Exam tip | 题型提示框。**该题型在本书中已出现过则不再提供说明** | 旧版 `Exam tip` / `Exam information` | `ADAPT` |
| 题型框 | `<考试> <Paper> Part N`（如 B2 First Reading and Use of English Part 4） | 大纲「考试技能」列 | `COPY` |
| 5a〔5b 5c〕 | 该题型的剑桥真题或模拟题实战 | 旧版对应技能栏目（UoE / Listening / Speaking / Writing） | `ADAPT` |

**关键约束**：具体题型由大纲「考试技能 / 听力 / 口语 / 写作」列决定；听力、阅读、语用题量 5 个左右；难度保持在 B1，不能太难。

## 6. 动作定义与来源标注

与知识清单一致：

| 动作 | 使用条件 | 必须记录 |
|---|---|---|
| `COPY` | 已确认来源可直接沿用，仅需字段或位置转换 | 来源引用、定位和规则版本 |
| `ADAPT` | 有确认来源，但需按目标结构、题型骨架或语言要求改写 | 原文、改动原因、改动范围和来源引用 |
| `GENERATE` | 旧版没有对应内容，目标模板要求补充 | 生成依据、规则版本、人工审核状态和来源标注 |
| `HOLD_IN_SOURCE_ONLY` | 当前没有目标模块，或需求方尚未决定去留 | provenance、待确认原因和禁止生成标记 |

统一来源标注（后台必填）：

```text
origin_type: COPY / ADAPT / GENERATE
source_refs: [confirmed source refs or approved evidence refs]
source_locator: module / section / page / paragraph / cell
rule_snapshot: generation-time rule snapshot
requires_human_review: true / false
```

## 制作原则（需求方 2026-09-16 确认）

制作阶段的目标是：**先把新版框架完整搭起来，然后尽可能把旧版内容映射过去，确实缺失的就留空**，等 AI 生成建议功能做好后再填充。

对迁移的具体含义：

1. 模块、小节、表格表头、题干、序号一律齐全——框架不因内容缺失而残缺；
2. 能由已确认来源映射的字段照常 `COPY` / `ADAPT` 填进去；
3. 来源确实没有的字段留空，**不写「（待人工确认）」这类占位文字**（占位文字会被误当成正文，也会挡住后续 AI 建议的填充）；
4. 留空范围与原因记入版本 metadata，不在正文里表达。

对应规则：`R-SB-005`（学生用书）、`R-KL-021`（知识清单）。
