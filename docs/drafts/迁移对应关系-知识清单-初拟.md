# 迁移对应关系（初拟）——旧版知识清单 → 通用新版知识清单模板

> **状态：初拟草稿，未经需求方最终确认，不作为正式规则。同步基线：profile.md V1.2，2026-09-22。** 本文件不能导入本地 Published 规则集，也不能据此硬编码迁移关系。
>
> 本稿根据旧版知识清单、新版 2.0 知识清单样本和一份新版在线文档样本整理。样本中的具体课程、学期、Lesson、Unit、主题和词汇只用于核对结构，不作为通用映射数据。
>
> 对应规则文件：`docs/drafts/规则文件-知识清单-初拟.md`。

> **单一事实源约定（草案）**：本文件只定义通用映射对象、动作语义、校验方式和大纲单元格的变更标注语法；不保存任何具体学期的实际映射。每个学期的实际映射和特殊结构变化只写在该学期现有格式的大纲相应单元格中，系统从大纲解析配置，不再维护第二份学期映射表。

## 1. 单一事实源与大纲单元格标注

### 1.1 文件职责

| 文件 | 只负责什么 | 不负责什么 |
|---|---|---|
| 通用规则草稿 | 内容 contract、迁移边界、检查和生成逻辑 | 不保存具体学期、Unit、Lesson 或词汇映射 |
| 本文件 | 映射对象模型、动作定义、校验和括号标注语法 | 不保存某个学期的实际映射数据 |
| 部门标准大纲 | 各学期 Lesson 数据、实际旧→新关系和本学期例外 | 不复制通用规则全文 |

大纲的原有列、Sheet 和部门格式不变。学期专属信息追加在已有相关单元格中，用标准化全角括号表达；括号外仍是面向教研人员阅读的原始内容。

### 1.2 括号标注语法（草案）

使用：

```text
（变更：key=value；key=value；reason=简短说明）
```

建议使用的 key：

- `source`：来源模块、来源栏目或来源 Lesson 引用；
- `target`：目标模块、目标栏目或目标 Lesson 引用；
- `action`：`COPY`、`ADAPT`、`GENERATE`、`HOLD_IN_SOURCE_ONLY`；
- `status`：`pending`、`confirmed`、`disabled`；
- `scope`：`lesson`、`module`、`section`、`book`；
- `template`：本学期使用的目标模板版本；
- `reason`：本学期变化的简短原因；
- `note`：供教研人员阅读的补充说明。

例如，以下只是**语法示例**，实际值必须写入对应学期大纲，不写入本文件：

```text
目标语法（变更：action=ADAPT；source=旧版语法栏目；target=目标语法块；reason=本学期模板调整）
阅读文章（变更：action=COPY；source=确认阅读材料；target=阅读词汇；status=confirmed）
复习内容（变更：action=HOLD_IN_SOURCE_ONLY；target=none；reason=当前模板没有对应目标块）
```

规则：

1. 一个单元格可以有多个括号标注；每个标注表达一个独立变更或映射。
2. 多对一/一对多关系通过多个单元格标注共同表达，不另建第二份学期映射表。
3. 括号外的原始字段值不可被解析器覆盖；标注解析失败时保留原文并进入待人工确认。
4. `action`、`source`、`target` 不完整时不得生成正式 Mapping；不得由模型补齐。
5. 解析后形成的标准化 Mapping 是大纲的运行时投影，不是另一份需要人工维护的事实源。
6. 若单元格原文自身需要使用括号，应使用普通文本括号并避免以 `变更：` 开头，或由导入器标记为待确认。

### 1.3 读取顺序

```text
部门标准大纲
      ↓ 解析单元格括号变更
学期/项目配置（运行时投影）
      ↓
ModuleMapping + Section Overrides + Lesson Profile
      ↓
Migration Plan / Generator / Validator
```

任何代码、规则 seed 或独立映射 Markdown 都不能覆盖大纲中已确认的学期配置；冲突时停止任务并提示人工。

### 1.4 新版层级术语

新版目标教材统一使用 `Lesson`，不使用 `Unit` 作为目标层级名称。大纲中的 `target_lesson_ref`、目标映射、Lesson Profile、生成标题、工作台标签和导出内容都应使用 `Lesson`。旧版来源若原文或来源定位使用 `Unit`，在 source quote、OCR、provenance 和历史引用中保留原文，不做无差别字符串替换；进入目标语境时再规范化为 `Lesson`。具体术语规则见规则文件 R-KL-020。

## 2. 映射原则

### 1.1 映射对象

旧版和新版的对应关系按结构化对象保存：

```text
SourceDocument
    ↓
SourceModule / SourceSection
    ↓
ModuleMapping
    ↓
TargetModule / TargetSection
```

不能只保存一条 `old_module_id → new_module_id` 字符串，也不能让模型根据名称相似或编号相同临时猜测。

每条映射至少应能记录：

| 字段 | 说明 |
|---|---|
| `project_id` | 所属项目 |
| `source_module_id` | 已确认的旧版模块 |
| `target_module_id` | 目标模板中的模块 |
| `source_section_key` | 旧版栏目或内容块 |
| `target_section_key` | 新版栏目或内容块 |
| `mapping_type` | `one_to_one`、`one_to_many` 或 `many_to_one` |
| `priority` | 多条候选的处理顺序，具体含义待确认 |
| `notes` | 人工说明、例外和待确认事项 |
| `status` | 映射确认状态，不解除来源确认要求 |

### 1.2 映射边界

- 映射必须明确项目、Lesson、来源书种和目标书种。
- 跨项目、跨 Lesson 或跨书种的来源不得自动带入。
- 映射支持一对一、一对多和多对一；多条记录共同表达关系。
- 映射成立不等于来源正文已确认。只有 `confirmed` 来源才能进入正式生产检索。
- 未映射来源可以作为明确标记的补充候选，但不能伪装为 `mapped_source`。
- Embedding 只能补充候选，不能建立映射或覆盖显式映射。
- 编号、名称、词汇相似度和版式相似度都不能单独作为映射依据。

### 1.3 当前样本核对出的目标范围

新版 2.0 样本显示，知识清单由若干主题 Lesson 和书级栏目组成，单课结构稳定；样本中没有独立的 Revision 知识清单课时。因此：

- 旧版的复习性/Revision 课时默认不生成目标知识清单；
- 这类来源保留在来源侧，标记为待处理，不自动塞入普通 Lesson 或书级栏目；
- 如果需求方将来提供 Revision 的目标模板，再新增目标模块、映射和专用规则；
- 当前不把“新版 Revision 格式”列为待确认事项，也不按旧版编号推导目标课时。

## 3. 模块级对应关系

### 2.1 旧版固定内容到新版栏目

| 旧版来源块 | 新版目标块 | 默认动作 | 对应方式与边界 |
|---|---|---|---|
| 词汇复习：核心/四会词汇 | `Let's say! → 核心词汇` | `ADAPT` | 旧字段重排为词卡字段；词条内容以确认来源或目标词表为准 |
| 阅读词汇及短语 | `Let's read! → 阅读词汇` | `ADAPT` | 保留词条、语境释义和阅读原句定位；不能把自动生成句子标为原文 |
| 语法复习 | `Let's talk!` | `ADAPT` | 迁移知识点和例句，按目标模板重排为说明、表格、注意事项和辨析 |
| 旧版附加栏目、手写区、复习建议或拓展阅读 | 目标模板中没有对应位置 | `HOLD_IN_SOURCE_ONLY` | 在需求方确认前不删除、不生成、不混入目标正文 |
| 复习性/Revision 课时 | 当前样本无对应知识清单模块 | `HOLD_IN_SOURCE_ONLY` | 不自动按编号生成；未来若有目标模板再建立映射 |

### 2.2 新版目标模板新增内容

| 旧版是否有直接来源 | 新版目标块 | 默认动作 | 依据和边界 |
|---|---|---|---|
| 通常没有 | 学习目标表 | `COPY` / 确定性映射 | 从 Lesson Profile 或已确认大纲写入目标词汇、核心语法、阅读文章、技能训练 |
| 通常没有 | 词形派生表 | `GENERATE` | 以确认核心词汇和授权词典/词表为依据，生成四列表格后逐格确认 |
| 通常没有 | 话题词汇表 | `GENERATE` | 以 Lesson 主题、目标大纲和授权资料为依据，数量由模板配置 |
| 通常没有 | 阅读技能块 | `GENERATE` | 以目标考试任务和当前阅读文章为依据，包含步骤、示例和证据分析表 |
| 书级内容可能有模板来源 | 考试题型总览 | `COPY` / `ADAPT` | 一书一次；题型、时间和题量以适用标准为准 |
| 书级内容可能有模板来源 | Writing Bank 或其他写作资料库 | `COPY` / `ADAPT` | 一书一次；模板素材和课程定制素材分开标注 |

### 2.3 新版课内默认顺序

目标模板未另行配置时，内容顺序为：

```text
学习目标表
    ↓
Let's say!
    ├── 核心词汇词卡
    ├── 词形派生表
    └── 话题词汇表
    ↓
Let's read!
    ├── 阅读词汇
    └── 阅读技能
    ↓
Let's talk!
    └── 语法说明与结构表格
    ↓
书级栏目（每本书一次）
```

课头、课尾、封面图、标题图标、页码徽标和字体排版不是本映射的内容对象；图片只通过 Asset 和 provenance 记录。

## 4. 字段级对应关系

### 3.1 核心词汇词卡

旧版的常见词条结构为：序号、等级、词头或词组、IPA、词性和中文释义、英文定义、例句、搭配、拓展和备注。新版样本将其重组为结构化词卡表格。

| 旧版字段 | 新版字段 | 动作 | 规则 |
|---|---|---|---|
| 序号 | `index` | `COPY` / `ADAPT` | 以目标词汇顺序重排，连续且不重复 |
| 等级标签 | `level` | `ADAPT` | 只改变表格位置，不改变经确认的值 |
| 词头或词组 | `word` / `phrase` | `COPY` | 多词表达的边界必须人工确认 |
| IPA | `ipa` | `ADAPT` | OCR 高风险字段，逐条对照原页面或授权词典 |
| 词性 | `part_of_speech` | `COPY` / `ADAPT` | 需与当前释义和语境匹配 |
| 中文释义 | `meaning_zh` | `COPY` / `ADAPT` | 以确认来源或目标词表为准 |
| 英文定义 | `definition_en` | `COPY` | 缺失时才允许生成并审核 |
| `e.g.` 英文例句 | `example_en` | `COPY` | 原句确认后保持不变 |
| 中文翻译 | `example_zh` | `GENERATE` / 人工校对 | 翻译不得改变英文原句语义 |
| 搭配 | `collocations` | `COPY` / `ADAPT` | 来源没有则留空，不得编造 |
| 拓展 | `expansion` | `COPY` / `ADAPT` | 每个拓展项都要有来源或审核依据 |
| Notes 或空白备注 | provenance / 审核备注 | 不直接进入正文 | 是否展示由模板配置决定 |
| 重点词标记 | `is_key_word` | `GENERATE` / 人工确认 | 没有选词标准不得自动加标 |

新版词卡至少应能还原为以下内容表格，不要求保留视觉卡片样式：

| 序号 | 等级 | 词头/词组 | IPA | 词性和中文释义 |
|---:|---|---|---|---|
| `index` | `level` | `word` | `ipa` | `part_of_speech` + `meaning_zh` |

并为每条词卡保存：英文定义、搭配、拓展、英文例句、中文翻译和来源标注。

### 3.2 词形派生表

新版模板的词形派生内容应转换为完整四列表格：

| 名词 | 动词 | 形容词 | 副词 |
|---|---|---|---|
| 已确认词形 | 已确认词形 | 已确认词形 | 已确认词形 |

规则：

- 以目标核心词汇为候选基础；
- 允许一个单元格有多个词形，但每个词形都需可追溯；
- `/` 只能表示人工核对后确认不存在或不适用的词形；
- 未知词形不能用 `/` 伪装成已确认的缺失；
- 不得为了填满四列生成不存在的词形。

### 3.3 话题词汇表

新版模板的补充词汇应结构化为：

| 序号 | 词条 | 词性 | 中文释义 | 来源/依据 |
|---:|---|---|---|---|
| 1 | 目标主题词 | `pos` | `meaning_zh` | 主题、大纲或授权资料 |

数量、重复规则和允许的资料层级由 Template Profile 或项目规则决定，不从某一个样本固定推导。

### 3.4 阅读词汇表

| 词条 | 词性 | 中文释义 | 阅读原句 | 来源定位 |
|---|---|---|---|---|
| `term` | `pos` | `meaning_zh` | 已确认原句 | 文章版本、段落或页码 |

阅读原句必须能回指当前目标阅读文章或确认的继承来源。模型新写的例句只能作为待审核 `GENERATE` 内容。

### 3.5 阅读技能分析表

阅读技能主题由目标考试任务驱动，不能固定绑定到某个课程或某个旧版讲次。完整内容至少包括：

- 技能名称和适用题型；
- 技能目标；
- 分步骤解题方法；
- 当前阅读文章中的示例；
- 题目、原文和推理证据的对应表。

| 题目/空格 | 题目中的表达 | 原文中的表达 | 关系类型 | 分析依据 |
|---|---|---|---|---|
| 题目标识 | 关键词或抽象概念 | 原文片段和定位 | 同义替换、指代、因果、转折或衔接 | 为什么能够对应 |

当前新版样本每课有一个与目标题型对应的阅读技能块；“所有课程是否固定一课一个技能块”仍需需求方确认。

### 3.6 语法表格

旧版语法表格和例句可以迁移到新版语法块。新版语法内容默认整理为：

| 内容层 | 输出要求 |
|---|---|
| 语法名称 | 使用目标大纲或已确认语法名称 |
| 用法说明 | 说明使用条件和语义功能 |
| 结构表格 | 展示结构、时态、形式或对照关系 |
| 例句 | 覆盖目标范围，标明来源或生成状态 |
| 注意事项 | 记录限制、例外和易混点 |
| 辨析/练习示例 | 仅在模板或规则要求时输出 |

语法点不因新版版式变化而自动增加。旧版缺失的内容只有在目标大纲或权威规则明确要求时才可 `GENERATE`。

## 5. 来源、动作和状态

### 4.1 三种迁移动作

| 动作 | 使用条件 | 必须记录 |
|---|---|---|
| `COPY` | 已确认来源可直接沿用，仅需字段或位置转换 | 来源引用、定位和规则版本 |
| `ADAPT` | 有确认来源，但需要按目标结构、字段或规则改写 | 原文、改动原因、改动范围和来源引用 |
| `GENERATE` | 旧版没有对应内容，目标结构或规则明确要求补充 | 生成依据、规则版本、人工审核状态和来源标注 |
| `HOLD_IN_SOURCE_ONLY` | 当前没有目标模块，或需求方尚未决定去留 | provenance、待确认原因和禁止生成标记 |

`HOLD_IN_SOURCE_ONLY` 不是正式教材内容，也不是可以直接提交的 Draft 目标块。

### 4.2 统一来源标注

每个内容块或可独立追溯字段至少保存：

```text
origin_type: COPY / ADAPT / GENERATE
source_refs: [confirmed source refs or approved evidence refs]
source_locator: module / section / page / paragraph / cell
rule_snapshot: generation-time rule snapshot
requires_human_review: true / false
```

没有真实来源时不得编造引用。`GENERATE` 可以引用已确认的大纲、Lesson Context 或规则作为依据，但必须让人知道它不是旧教材原文。

### 4.3 状态门禁

```text
Provenance / Pending
        ↓ 人工核对
Confirmed Production Source
        ↓ 迁移规划
Draft Module Version
        ↓ 老师确认
Confirmed Module Version
```

任何一步失败，都不能用 Mock、placeholder 或 Embedding 结果绕过门禁。

## 6. 生成类内容的来源缺口

| 目标内容 | 首选依据 | 允许的动作 | 不能做的事 |
|---|---|---|---|
| 学习目标表 | Lesson Profile、目标大纲 | 确定性映射 | 不能由模型自行补目标 |
| 英文例句中文翻译 | 已确认英文例句 | `GENERATE` + 人工校对 | 不能改写英文原句 |
| 重点词标记 | 已确认选词标准 | 人工确认后 `ADAPT` | 没有标准不能自动标记 |
| 词形派生表 | 核心词汇、授权词典/词表 | `GENERATE` + 逐格确认 | 不能用假词形或未知 `/` |
| 话题词汇表 | Lesson 主题、目标大纲、授权资料 | `GENERATE` + 逐条确认 | 不能把相似词当作事实 |
| 阅读技能讲解 | 目标考试任务、当前阅读文章 | `GENERATE` + 审校 | 不能套用其他题型的内容 |
| 阅读词汇例句 | 当前阅读文章或已确认继承来源 | `COPY` / `ADAPT` | 不能把生成句标为课文原句 |
| 语法新增内容 | 目标大纲、权威规则、已确认旧版 | `GENERATE` + 人工确认 | 不能因模板骨架自行扩展语法 |
| 书级考试/写作栏目 | 已确认模板或标准 | `COPY` / `ADAPT` | 不能每课重复生成 |
| 复习性/Revision 课时 | 当前样本无对应目标知识清单 | `HOLD_IN_SOURCE_ONLY` | 不能按编号自动生成目标课 |

## 7. 本地版迁移执行顺序

1. 读取 Lesson Profile 和目标 Template Profile。
2. 对来源文件执行 OCR、页面结构识别和模块切分，但将这些结果保留在 provenance 层。
3. 由人工核对来源正文、表格、音标、词性、例句和阅读原句，发布为 confirmed source。
4. 创建显式 ModuleMapping，检查项目、Lesson、书种和映射类型边界。
5. 以结构化检索取得已确认来源；Embedding 只有在任务明确开启时作为补充候选。
6. 构建分章节 Context 和 Effective Rule Set，保存规则快照及检索 trace。
7. 先生成 Migration Plan，再逐块选择 `COPY`、`ADAPT`、`GENERATE` 或 `HOLD_IN_SOURCE_ONLY`。
8. 生成完整学习目标表、核心词卡、词形派生表、话题词汇表、阅读词汇表、阅读技能分析表和语法表格；不生成排版、美术或假占位内容。
9. 执行确定性检查：章节顺序、表格完整性、词汇覆盖、重复、来源状态、原句定位、映射边界、来源标注和预算。
10. 对自然度、难度、翻译和教学解释执行 LLM Review，输出建议而不是自动修改正文。
11. 老师确认正文和待确认项后保存新的 Module Version；重新生成不得覆盖人工修改稿。
12. 输出结构化内容包，交由后续排版流程处理字体、分页、图片和图标。
