## 1. 学生用书

| 核查项 | 要求 |
|---|---|
| 二维码 | `26秋下-学生用书-第X课` |
| 页脚 | 页码 + 序号顺次，不能被图片遮盖 |
| 封面 | 季节【Autumn 9-15】名称【Student's Book】层级【LEVEL 5】 |
| 目录 | 标题按大纲核对完整（拼写、大小写、标点）；页码无遗漏、顺序正确 |
| 附录 | 附录单词按大纲核对完整 |
| 图片 | 符合脚本文字或课次主题；无负面元素（纹身、耳钉等）；**Let's read! 里的图片人物数量与类型须与文章一一对应** |
| 主题页 | `In this lesson, we will...` + 四条（learn words… / read the article… / learn the grammar of… / listen to a…） |
| Let's explore! | `1a Did you know...` 课文前导短文，**包含本课所有核心词汇** |
| Let's say! | 2a 小短文含核心词汇；2b 英文释义选词；2c 标星词原型与派生二选一 |
| 单词题目 | 考全（所有单词考到一遍）、拼写大小写无误、难度由易到难、不超纲、答案唯一且分布不集中 |
| Let's read! | 3a 阅读前导入（讨论题）；3b 阅读文章 + 句子挖空/单项选择 + SKILLS 讲解框；3c 开放观点题 2 道左右 |
| 阅读题目 | 必须从原文找到定位，不能通过图片得出；SKILLS 与本课阅读题目相关，讲解 + 练习 |
| Let's talk! | 4a 基础语法规则填空/识别，特殊用法入 LOOK 提示框；4b–4c 巩固（单选、变形、选词）；4d 综合运用；每部分约 5 题 |
| Let's use! | 5a Exam tip（**已出现过的题型不再给说明**）+ 剑桥 FCE/PET 原题或模拟题实战 |
| 通用 | 单词拼写、语法句子一律**英式英语** |

## 2. 练习册

| 核查项 | 要求 |
|---|---|
| 二维码 | `26秋下-练习册-第X课` |
| 页眉 | `Lesson 【9-15】`，注意 `Lesson` 大写 |
| 封面 | 季节【Autumn 9-15】名称【Workbook】层级【LEVEL 5】；目录与学生用书保持一致 |
| 各级标题 | 拼写、大小写规范；标题与配套小图标一一对应；涉及考点时考点用斜体；`circle`/`cross out` 用天蓝色圈划；语法课次加 REWARD STAMP，课外阅读与考试模块加难题图章 |
| **Day 1+2+3** | 每天都含 `let's say` 单词与 `let's talk` 语法两部分，**每天每部分 1–2 题，难度逐天提高**。单词题型：补全拼写/根据定义选词/根据下划线定义选替换词/情景选择题/选词填空（不变形）/二选一变形填空（同学生用书 2c）。语法题型：判断题/情景选择题/二选一不填空版/选词填空/改错 |
| **Day 4** | 对应 `let's read`，形式多样的阅读题；题型与学生用书保持一致，主题相关；人物与话泡内容匹配，话泡自上而下自左而右；答案能在确切文段找到，出题顺序与文段出现顺序一致；注意题目中 `They` 出现的时机 |
| **Day 5** | 对应 `let's use`，考听力与写作，**听力占比较大**，须满足 `write one word or a number`。格式：1 语法练习；2 剑桥考试听/说/读/写模拟题 |
| 题目通用 | 首次出现的题型**必须加示例（Example）**，示例文本和答案全部加蓝色；考全；正确性；难度梯度；不超纲；答案唯一；答案分布不集中；书写区长度足够；无多余内容 |
| **注意事项** | 练习册所有题目**基于学生用书**，考点需与学生用书**一一对应**，且考点**不能超纲学生用书**，题型与学生用书基本保持一致 |

## 5. 这些要求将来怎么用

AI 修改建议功能落地时（profile.md §7.2 / Local-4）：

1. 把本文件的条目转成**审校/修改规则**（`rule_type = review`），按作用域绑定；
2. 老师在某个 Module 上提修改要求时，这些规则作为**红线**进入 Context Pack，
   约束大模型「不得改出新版也不接受的形态」；
3. 规则快照随建议一起保存，便于历史复现。

**在此之前不要把它们塞进生成骨架**——迁移阶段的目标是把旧版内容完整搬过来，
内容是否符合新版要求由老师后续判断和修改。
