# 术语表（初版，待 Round 1/2 确认）

| 术语 | 当前含义 | 待确认点 |
| --- | --- | --- |
| Rules as Data | 将教材结构模板、生成规则和审校标准存为可管理文本，并参与 Prompt 组装 | 规则是否需要结构化字段、版本和审批状态 |
| 生成规则 | 驱动某个书种/模块生成内容的规则 | 适用范围、优先级、冲突处理和发布方式 |
| 审校规则 | 驱动生成内容检查的规则 | 审校是阻断式、建议式还是两者都有 |
| Lesson | 一次完整课程/一课，是用户最终编辑和导出的工作对象 | Lesson 的编号、课程映射、状态和唯一 ID 待确认；不再使用 `Unit` 作为正式术语 |
| 知识库条目 | 供 Lesson 模块生成和审校使用的事实、课程内容或规范素材 | 结构、来源、版权、检索方式和版本尚未敲定 |
| 教材记录 | 保存某个 Lesson 当前正文及其版本信息的记录 | 需要区分工作文档、不可变版本和 DOCX 导出快照 |
| 模块 | 书种下可单独生成的内容单元，如 `Let's say!` | 是否有稳定 ID、顺序、输入依赖和输出 schema |
| `used_rules` | 生成时使用过的规则记录 | 是否扩展为不可变的规则/知识/Prompt/模型快照 |
| 生成任务 | 用户点击模块后创建的异步任务 | 状态机、幂等键、重试、取消和结果绑定待确认 |
| 审校报告 | AI 对教材内容运行审校规则后产出的报告，由人工复核 | 报告结构、严重级别、人工结论和 DOCX 形式待确认 |
| 公司多模型 API | 公司提供的模型网关，可调用 GPT 5.6、GLM 5.2 等模型 | 接口协议、参数兼容、默认模型、路由与回退策略待确认 |
| Lesson 工作包 | 同一课下强绑定的四个书种文档及其共享上下文，是最终审校的基本单位 | 四书的具体同步字段和完成条件待确认 |
| 迁移生成 | 检索上一版教材内容，并按照新版结构规则重组为模块 draft | 旧新 Lesson 映射、复用强度和缺口生成策略待确认 |
| 改进建议 | 基于剑桥内容和既定规则，对 draft 提出新增、替换或局部修改建议 | 建议是否自动应用、如何引用证据待确认 |
| 来源链路 | 从生成或建议结果回溯到旧版内容块、剑桥依据、规则版本、模型和参数的记录 | 用户界面展示粒度与保存期限待确认 |
| 四书同步 | 保持同一 Lesson 四个书种之间的核心教学事实和依赖内容一致 | 自动覆盖、建议确认或阻断检查的边界待确认 |
| 教师反馈事件 | 老师对生成结果或建议执行接受、拒绝、改写并可附原因的结构化记录 | 后续用于规则优化、示例检索或训练的治理方式待确认 |
