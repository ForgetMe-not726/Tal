# ADR-0002：以 Lesson 为工作对象，按模块异步生成并人工编辑

- 状态：已接受
- 日期：2026-08-26

## 背景

产品面向公司内部教研员，多小组共同生产教材。用户希望按一个模块按钮生成一段内容，在中间区域继续人工修改，直到完整的一课完成并导出。

## 决策

- 正式工作对象称为 `Lesson`，不再使用 `Unit`。
- 一个 Lesson 是包含四个强关联书种文档的工作包；每份书种文档由多个有稳定标识的模块内容块组成。
- 点击模块创建异步生成任务；任务成功后将结果绑定到目标 Lesson 和目标模块。
- 用户可在工作区修改生成结果；完整 Lesson 首个导出目标为 DOCX。
- 审校由 AI 自动执行并产出审校报告，报告交由人工复核。

## 后果

- 数据模型至少需要 Lesson 工作包、四个书种文档、文档版本/草稿、模块定义、模块内容块、生成任务、审校任务和审校报告。
- 异步结果必须携带 Lesson ID、模块 ID、请求幂等键和基于哪个正文版本生成的信息，避免跨小组或跨 Lesson 串写。
- 前端原型的同步 `setTimeout` 与只读 Markdown 只是演示，不是正式实现方式。
