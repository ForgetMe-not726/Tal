# ADR-0005：将现有审校 Skill 迁移为版本化审校 Profile

- 状态：已被 ADR-0006 取代
- 日期：2026-08-26

## 背景

最初假设现有 `pet-material-review` Skill 可以作为新版审校内容和回归测试基线。用户随后确认该 Skill 尚不完善，且具体内容与新版教材存在出入。

## 决策

- 本 ADR 的“以现有 Skill 作为规则和回归测试基线”决定不再成立，后续按 ADR-0006 执行。
- 将 review list、判断标准、语法章节和交付 schema 迁移为可版本化 `ReviewProfile`，按教材版本、年级、考试目标和书种绑定。
- 每次 `ReviewRun` 固定输入的四书版本集合和 profile 版本，生成结构化 findings，再适配 Web 与 XLSX 输出。
- 内容审校与最终 PDF 视觉审校分成两个可独立运行的关卡。
- 不让人工反馈自动覆盖 Cambridge、事实时效、英式英语、答案唯一性等上位硬门槛。

## 后果

- 需要保留当前 Skill 的覆盖验证和报告生成测试，作为 Web 审校引擎的回归基准。
- 新版结构或新考试目标必须创建新 profile 版本，不能直接修改历史运行所引用的规则。
- Web 中的一键应用修改正文时必须产生新文档版本，并保留 finding、原文和修改结果的关联。
