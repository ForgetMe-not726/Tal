# ADR-0006：现有审校 Skill 只作为流程参考

- 状态：已接受
- 日期：2026-08-26

## 背景

现有 PET 教材审校 Skill 具备原子化 review list、证据判断、材料不足状态、结构化报告和人工复核等可借鉴方法，但它尚不完善，且具体内容与即将制作的新版教材存在差异。新版大纲尚未发布。

## 决策

- 只借鉴现有 Skill 的通用流程和数据形态，不迁移其具体审校规则。
- PET/B1–B2、38 条源行、题型数量、LEVEL 5 和版式要求不进入新版规则库。
- 新版大纲发布前，只设计稳定的 ReviewProfile、ReviewRun、ReviewFinding、建议审阅、版本快照和报告接口。
- 新版大纲发布后，以新版大纲为上位依据重新编写 review list、审校标准、知识映射和回归样例。

## 后果

- 当前架构不会被旧教材结构锁死。
- 旧 Skill 的测试结果不能作为新版审校引擎的正确性证明。
- 新版规则需要独立的教研确认、版本发布和真实教材回归测试。
