# ADR-0001：先完成方案澄清，再进入实现

- 状态：已接受（工作流程决策）
- 日期：2026-08-26

## 背景

当前工作区只有一份产品/技术方案文档，没有可运行代码、数据库迁移或部署配置。方案中还存在影响架构的未决问题，包括权限模型、规则版本、教材版本、审校门槛、任务状态和数据追溯。

## 决策

将当前项目视为设计澄清阶段。先用 `grill-with-docs` 的 grilling 与 domain-modeling 两轮访谈收敛关键分叉；在关键问题获得确认前，不把示例字段或流程描述当作最终实现契约。

## 后果

- 当前产出以风险清单、问题、领域模型、ADR 和验收标准为主。
- 实现阶段必须以确认后的文档为输入，并为权限、版本追溯、幂等和审校阻断提供可测试证据。
- 早期不能仅凭 UI 草图或一次成功的模型调用判定方案可交付。
