# ADR-0004：拆分迁移生成、改进建议与整课审校

- 状态：已接受
- 日期：2026-08-26

## 背景

新版教材大体复用上一版内容，但结构发生显著变化。产品既要把旧内容重组到新版结构，也希望依据剑桥内容和规则提出改进建议，并在四个书种完成后执行整课审校。

## 决策

将 AI 流程拆为三个可独立追溯和重试的阶段：

1. 迁移生成：上一版教材内容 + 新版结构规则 → 模块 draft。
2. 改进建议：当前 draft + 剑桥内容 + 质量规则 → 建议，不默认覆盖正文。
3. 整课审校：固定的四书版本快照 + 审校规则 → 详细报告，交由人工复核。

同一 Lesson 的四个书种作为一个强关联工作包。四书完成且没有未处理冲突后，才允许进入整课审校。

教师反馈驱动的自动进化不纳入当前及格线。当前阶段记录结构化反馈事件，未来再决定用于规则优化、案例检索或受控训练。

## 后果

- 三个阶段需要独立任务类型、Prompt 模板、输入快照、状态和错误处理。
- 改进建议与正文必须分开存储，只有老师接受后才形成新的正文版本。
- 审校报告必须绑定不可变的四书版本集合。
- RAG 结果不能只返回文本，还必须返回来源标识、版本和定位信息。
